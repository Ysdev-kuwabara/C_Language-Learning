このコードの主な問題点を指摘します。
1. 一番大きい問題：scanf失敗時に未初期化変数を使っている（未定義動作）
Cif (scanf("%d",&score) <= 0 || score > 100) {

scanf が失敗した場合（文字を入力したなど）、score には何も代入されません。
その状態で score > 100 を評価してしまうため、未初期化の変数を使っていることになります。
これは未定義動作（Undefined Behavior）で、実行結果がどうなるか保証されません。

正しい考え方は「まず scanf の戻り値を確認し、成功した場合だけ範囲チェックする」です。
2. 入力エラー時の対応が不十分

エラーが出たらすぐに return 1 で終了している。
ユーザーに再入力の機会を与えていない。
初心者向けの練習としては「入力が正しくなるまで繰り返す」形の方が学習効果が高い。

3. 負の点数の扱いが曖昧

score > 100 しかチェックしていないので、-10 のような値は通ってしまい、最終的に F になる。
テストの点数として負の値を許可するかどうかは設計次第だが、「正しい点数を入力してください」と言うなら、0〜100 の範囲外はすべて弾く方が自然。

4. 細かい点

スペルミス：Assesment → Assessment
scanf の戻り値チェックが <= 0 になっているが、通常は != 1 と書く方が意図が明確（成功時は必ず1を返す）。
エラーメッセージが「Please enter correct score」だけで、何が悪かったのかがわかりにくい。

改善の方向性（参考）
最低限直すなら、こんな形が安全です：

if (scanf("%d", &score) != 1) {
    printf("Please enter a valid number.\n");
    return 1;
}
if (score < 0 || score > 100) {
    printf("Please enter a score between 0 and 100.\n");
    return 1;
}

さらに良くするなら、while で正しい入力が来るまで繰り返す形にすると、Phase 1の「入力ミスへの対応」の練習としてより適切です。
