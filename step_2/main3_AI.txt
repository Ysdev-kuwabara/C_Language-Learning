よく書けています。Phase 1の「条件分岐＋入力ミス対応」の練習として十分に良いです。

### 良い点
- `scanf`の戻り値をチェックして、数字以外の入力を弾いている。
- バッファに残ったゴミを`while (getchar() != '\n');`で捨てている（ここを忘れがちなので良い習慣）。
- うるう年の判定ロジックが正しい（400で割り切れる → 100で割り切れる → 4で割り切れる の順）。
- `while (1)`で再入力を促している。

### 改善した方が良い点
1. **出力の末尾に改行がない**  
   結果表示の`printf`に`\n`を付けないと、次のプロンプトやシェルの表示がくっついて見づらくなります。

2. **プロンプトが少し曖昧**  
   「Please enter a number:」より「Please enter a year:」の方が意図が明確です。

3. **負の年や0の扱い**  
   今の段階では必須ではありませんが、負の年や0を入れたときの挙動を意識しておくと後で役立ちます（今はそのままでOK）。

### 修正版（最小限の改善）

```c
#include <stdio.h>

int main(void) {
    int year, result;

    while (1) {
        printf("Please enter a year: ");
        result = scanf("%d", &year);

        // 入力が数字じゃなかった場合
        if (result != 1) {
            printf("Invalid input. Please enter a number.\n");
            // バッファに残ったゴミを捨てる
            while (getchar() != '\n');
            continue;
        }

        break;
    }

    if (year % 400 == 0) {
        printf("%dはうるう年です。\n", year);
    } else if (year % 100 == 0) {
        printf("%dはうるう年ではありません。\n", year);
    } else if (year % 4 == 0) {
        printf("%dはうるう年です。\n", year);
    } else {
        printf("%dはうるう年ではありません。\n", year);
    }

    return 0;
}
```
